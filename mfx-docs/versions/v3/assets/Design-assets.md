# MarketFlip — Design Asset Inventory

A complete checklist of custom icons, animated assets, and free resources
to give MarketFlip its own visual identity.

Every asset includes:
- **Recommended size** — the ideal dimension for this use case
- **Acceptable range** — the min/max dimensions where it still looks good

---
